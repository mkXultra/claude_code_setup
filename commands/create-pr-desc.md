# 目的
pr_desc.mdを作成する

# 手順
1. 以下のコマンドでpr.diffを作成
   ```bash
   git diff $1...HEAD -- . ':!package*.json' ':!package-lock.json' ':!pnpm-lock.yaml' > pr.diff
   ```
2. `.github/pull_request_template.md` のフォーマットでpr_desc.mdを作成

# テンプレート
`.github/pull_request_template.md` が存在しない場合は、以下のテンプレートを使用：

```markdown
## 関連Issue ※ すでに紐づいている場合は省略可能
<!-- 関連するIssueがあれば記載してください -->
Closes #

## 概要
<!-- このPRで実装する機能の概要を簡潔に説明してください -->

## 現象と原因
<!-- バグの場合に簡潔に説明してください -->

## 対応計画・内容
<!-- 具体的な修正内容を箇条書きで記載してください -->
- [x] app.vueをxxxに変更(サンプル)
- [ ]
- [ ]

## 技術的な変更点 ※ チーム共有が必要な場合、起票後に共通お願いします
<!-- 技術的な変更があれば記載してください -->

## 対応結果
### スクリーンショットなど
<!-- UI変更がある場合はスクリーンショットを添付してください -->

## 対応確認
### テスト観点・ケース

### チェックリスト
- [ ] 対応内容が要件を満たしている。またはその認識合わせができている
- [ ] テストケースのテストが通っている
- [ ] ドキュメントが更新されている（必要に応じて）
```

# 注意事項
- 以下の項目はセクションを削除せずTODOとして残す：
  - スクリーンショット・画像
  - Issue番号・チケット番号
  - レビュアー・担当者の指定
  - デプロイ手順・特別な確認事項
  - その他、コードから推測できない情報
- 絶対にコミットはしない
