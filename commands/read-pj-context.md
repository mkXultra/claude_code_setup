# 目的
カレントディレクトリの `.ai/.llm` ディレクトリ内のファイルをすべて読み込み、プロジェクトのコンテキストを理解する。

# 手順
1. まず `.ai` ディレクトリが存在するか確認する
   - **重要**: `.ai` ディレクトリが存在しない場合は、即座に処理を中止し、ユーザーに報告する。他のファイルの検索や読み込みは一切行わないこと。
2. `.ai` ディレクトリが存在する場合のみ、`.ai/.llm` ディレクトリ内のすべてのファイルを検索する
   - Globツールで `.ai/.llm/**/*` パターンを使用
3. 検出したファイルをすべて読み込む
4. 読み込んだ内容を基にプロジェクトの以下を把握：
   - プロジェクトの概要・目的
   - 技術スタック
   - アーキテクチャ
   - コーディング規約
   - その他の重要なコンテキスト

# 出力
読み込んだコンテキストの要約を簡潔に報告する。

# 注意事項
- `.ai` ディレクトリが無い場合は即座に中止し、他のファイルを探そうとしないこと
- バイナリファイルは読み込まない
- 読み込んだ情報は以降のタスクで活用できるよう記憶する
